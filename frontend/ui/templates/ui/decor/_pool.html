{# What the ceiling collects in. AUTHORED, not ported: solutioning/portfolio-mockups.html styles a `.pool` (l.337-341) and never draws one, so this is the one asset of this world with no original to copy. Drawn to the band's idiom -- `preserveAspectRatio="none"` so it stretches to any width, no stroke, no gradient, colour through the token. Two paths rather than one: the surface, and a flatter darker body under it at .55 so the pool reads as having depth instead of as a flat bar. The top edges undulate in cubics and never come to a point -- a sharp crest would read as a drip, and this is the thing drips land IN. #}
